# CAAC 超视距多旋翼刷题站

1173道原题、51集课程方法与视频。原题ID、题库ID和旧本机记录键保持不变。

## 新功能

- 用时专项：只计题目前台有效用时；最近一次作答不足20秒为低档，20至40秒为中档，超过40秒为高档。旧记录无用时不分类，提前看解析不计时评分。
- 模拟考试：120分钟、随机100道不同单选题，选项随机重排。80分合格；交卷前不显示正误或解析，到时自动交卷，刷新不延长截止时间。交卷后按章节提供补足建议。此为用户指定练习规则，不声称是当前官方考试配置。
- 云端进度：选择张佳昊、纪亚群或黄春林，同名跨设备同步。按用户明确要求仅选姓名，无密码，姓名不是身份验证；持有网址的人可以切换这三个名字。
- 断网缓存：每次作答先写本机操作队列，恢复网络后补传。记录追加保存，使用唯一操作ID避免重试重复计数，云端原始事件不允许匿名修改或删除。
- 文字备份：点“复制进度备份”，可自行粘贴到微信文件传输助手；长备份分段复制。其他浏览器粘贴全部分段、校验后恢复到本机或指定姓名，重复旧备份不累加同一段历史。

## 旧记录

升级后默认本机访客，旧记录不会自动归给某个人。请先复制备份，再选姓名，通过“导入本机旧进度”或“粘贴恢复”合并。重叠题目保留提交次数较多的那份记录，原本机记录保留；建议不同旧设备的备份分别保管。

## 构建

从仓库根目录执行 `python source-v2/build.py --output index.html`。生成单文件页面，course-media与course-notes保留。云端配置是可公开的Supabase publishable key，仓库不含服务端密钥。schema.sql是已执行的初始结构，仅供审阅，不要在已有数据库重复执行。

GitHub Pages从main分支根目录发布。Supabase项目当前使用免费方案，额度、暂停规则及未来价格以供应商政策为准。

课程笔记保留来源时间、适用条件与存疑项，未将旧课程说法当现行法规。原视频多为HEVC，播放取决于浏览器解码支持。
