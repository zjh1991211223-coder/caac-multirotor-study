# CAAC 多旋翼刷题训练台

用于 CAAC 超视距多旋翼个人练习的静态网页，含 1173 道题、10 个章节。

- 单击选项立即判题；答对自动下一题，答错显示答案和解析，有视频时尝试在线播放。
- 可选择章节、题目、每轮题数、题目顺序、解析内容。
- 本机进度、正确率、错题专项和薄弱章节建议；支持进度备份、恢复。
- 每个人的进度独立保存在当前浏览器 localStorage，不会上传到本仓库，也不会跨设备自动同步。

题目来自低空玩家 2026-10-19 数据快照。答案按来源保留，未做 CAAC 官方认证或法规时效及专业正确性复核；外部视频链接的可用性由来源决定。

本项目为单文件静态网页，无后台账号、密钥或个人练习数据。GitHub Pages 从 main 分支根目录发布。
